ゲームの詳細（仮）

MazeRun は、ランダム生成される迷路を探索しながらコインを集め、能力を強化してタイムを縮めていく成長型タイムアタックゲームです。

こだわった点（仮）

迷路生成アルゴリズム、プレイヤーの操作感、強化システムのバランス調整に力を入れました。

制作背景（仮）

Unity を使った個人制作で、短時間で繰り返し遊べるゲームを目指して開発しました。

ゲームの詳細（仮）

Magic は、魔法を使って敵を倒しながら進む 2D アクションゲームです。シンプルな操作で爽快感を得られるように設計しています。

こだわった点（仮）

魔法のエフェクト、敵の動き、ステージ構成など、短時間で遊べる中でも気持ちよさを感じられるように調整しました。

制作背景（仮）

Unity の 2D アクション制作の練習として作成しました。プレイヤーの操作感と魔法の演出を重点的に作り込みました。
